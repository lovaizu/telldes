# Design doc template

> Rules（書くときにこの節は消す）
>
> - 読む人は直す人。変更が目的に合うかを、これだけで判断できる
> - README と実装から読めることは書かない。使い方は README、仕組みはコード、履歴は git
> - 決定は Decision / Why / Trade-off の3行に固定。理由の無い決定は書かない
> - 見出しは英単語。1決定 = 1見出し
> - 図・表で見せる。文は3行まで続けない
> - 未検証の事実は「未検証」と書く。推測を事実に見せない
> - 参照は最小。他文書の節を指さず、その場で1行で言い切る
> - 網羅しない。迷いそうな決定だけ残す
