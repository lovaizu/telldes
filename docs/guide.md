# Figmaのデザインを、CCに渡すzipにする

Figmaのファイルを用意してからClaude Code（以下CC）に渡すzipができるまでの手順。用意するものは、Figma（無償版でよい）と、Telldesを開ける状態（[README](../README.md) の「はじめる」）。

プラグインの画面にはFramesとTokensの2つのタブがある。FramesにはWebページとそのフレーム・レイヤー、Tokensにはトークン（CCがCSSの変数にする色・数値・書体・文字・影）が並ぶ。一覧の行を押すとその行の詳細が開く。ファイル全体の設定は上部のファイル名を押すと開く。

## 1. Webページを置いたFigmaのページを選ぶ

ファイル全体の設定のPagesでWebページのフレームを置いたFigmaのページを選ぶ。部品置き場や下書きのページは選ばない。

```
sample-site
├─ Visual Direction   ← 選ばない（下書き）
├─ Layout             ← 選ばない（下書き）
├─ Components         ← 選ばない（部品置き場。使った部品は、そのバリアントごと部品として渡る）
└─ Production         ← 選ぶ
```

選んだページの直下にある表示中のフレームがFramesタブに並ぶ。フレームでないもの（直下に置いたComponent・Rectangleなど）と非表示のレイヤーは渡らない。これらはFramesタブにNot exportedとして並び、zipの `README.md` にも書かれる。

## 2. 幅とテーマのサフィックスを決める

Telldesでは、PCとスマホのような幅の違いと、ライトとダークのようなテーマの違いを、名前の末尾（サフィックス）で表す。Figmaの無償版では1つの変数に幅やテーマごとの値を持たせる機能（モード）が使えない。その代わりに、フレームと変数に同じサフィックスを付けると、Telldesが「同じものの幅違い・テーマ違い」としてまとめ、CCは幅とテーマで切り替わるページを作る。

使うサフィックスをファイル全体の設定で決める。

| 設定 | 例 | 決めること |
|---|---|---|
| Breakpoints | `-pc`（From width 1024）、`-mobile` | 幅ごとのサフィックスと、その幅を使い始める幅（From width）。一番狭いものはFrom widthを空にする |
| Themes | `-light`、`-dark` | テーマごとのサフィックス。最初のものが、はじめに表示するテーマになる |

幅を1つしか描かないならBreakpointsは空、ダーク対応しないならThemesは空でよい。

### フレームに付ける

幅ごとに別のフレームで描き、フレーム名の末尾に幅のサフィックスを付ける。サフィックスを除いた名前が同じフレームは1つのWebページになる。

```
Production
├─ top-pc           ┐
├─ top-mobile       ┘ Web ページ「top」（PC とスマホ）
├─ article-pc       ┐
├─ article-mobile   ┘ Web ページ「article」
└─ campaign         ← サフィックスが無い。どの幅でもこの1枚を使う Web ページ「campaign」
```

テーマごとにフレームを描き分ける必要は無い。テーマは変数で切り替える（下）。

### 変数に付ける

幅やテーマで値を変えたい変数は、コレクション名か変数名の末尾にサフィックスを付けて、サフィックスごとに1つずつ作る。サフィックスを除いた名前が同じ変数は1つのトークンになる。サフィックスの無い変数はどの幅・テーマでも同じ値のトークンになる。

```
コレクション「Color-light」   bg = #FFFFFF   fg = #1A1A1A   ┐ トークン bg・fg
コレクション「Color-dark」    bg = #121212   fg = #EDEDED   ┘ テーマで切り替わる

コレクション「Spacing-pc」    section = 96                    ┐ トークン section
コレクション「Spacing-mobile」section = 48                    ┘ 幅で切り替わる

コレクション「Base」          radius/md = 8                   ← どこでも同じ
```

サフィックスはコレクション名でなく変数名に付けてもよい（`bg-light` と `bg-dark`）。有料プランでモードを使うなら、モード名をサフィックスと同じ名前（`light`・`dark`）にすれば、同じように読む。

デザインでは、幅の違うフレームには、その幅の変数をつなぐ。`top-mobile` のフレームには `Spacing-mobile` の変数、`top-pc` には `Spacing-pc` の変数を使う。色は最初のテーマ（`-light`）の変数につなぐ。

こうして渡すと、CCは `section` を「1024から96、それより狭いと48」のCSSの変数に、`bg` を「ライトでは白、ダークでは黒」のCSSの変数にする。

## 3. Setupでトークンをそろえる

TokensタブのSetupを押すと、推奨の一式のうち、足りないものだけが作られてTokensタブに並ぶ。テーマで変わる色は決めたテーマのサフィックスごとのコレクションに作られる。2回押しても増えず、手で作った同じ名前のものは上書きされない。足りないものがあるあいだはTokensタブに印が出る。名前はそのまま使い、値はデザインに合わせて変えてよい。

作られるものは次のとおり。

- テーマごとのコレクション（`Color-light`・`Color-dark` など）に、それぞれ14色
  - bg、surface、border
  - fg/default、fg/muted
  - primary/default、primary/hover、primary/on
  - link
  - code/bg、code/fg
  - notice/bg、notice/fg
  - shadow
- Baseコレクション（どこでも同じ値）に余白・角丸・書体
  - spacing: xs=4、sm=8、md=16、lg=24、xl=32、2xl=48、3xl=64、4xl=96
  - radius: sm=4、md=8、lg=16、xl=24、full=9999
  - font: heading、body、mono
- Text Style: display、heading-lg、heading-md、heading-sm、lead、body、label、caption、code
- Effect Style: shadow-sm、shadow-md

幅で変えたい余白などは、手順2のとおり、幅のサフィックスを付けたコレクションに作る。

## 4. デザインする

Figmaのいつものやり方でデザインする。したことは次のようにCCに渡る。

| Figmaでしたこと | CCに渡るもの |
|---|---|
| Auto Layoutで並べた | 並び・間隔・伸び縮み |
| Auto Layoutを使わずに置いた | 座標のまま（伸び縮みは伝わらない） |
| 変数・Text Style・Effect Styleにつないだ | トークンの名前 |
| つながずに値を入れた | 値のまま |
| 部品（コンポーネント）を置いた | 部品として一度だけ渡り、ページには「どの部品の、どのバリアントか」が渡る |
| 写真・ラスター画像 | PNGの画像 |
| アイコン・ロゴ（ベクター） | SVGの画像 |
| CSSで同じに描けないもの（特殊なグラデーション、破線など） | Figmaが描いた画像 |

部品にバリアント（Hover・Disabledなどの状態、Sizeなどの種類）を作っておくと、ページで使っていないバリアントも、すべて部品と一緒に渡る。CCは部品を一度作り、ページではそれを使い回す。ホバーのような状態は、noteに書かなくても、バリアントとして描けば伝わる。

トークンになるのは次のもの。

- 変数のColorとNumber
- 変数のStringのうち、使える場所（Scope）にFont familyかFont styleを含むもの
- Text StyleとEffect Style

次のものはトークンにならず、TokensタブにNot exportedとして並ぶ。使った箇所には値がそのまま渡る。

- Color Style。色は変数にする
- 変数のStringのうち、文字の中身に使うもの（ScopeがText content）と、変数のBoolean

## 5. 決めることを欄に入れる

Framesタブの行を押すと詳細にExport settingsの欄が出る。入れたものはファイルに保存される。

| 欄 | 開く行 | 入れるもの |
|---|---|---|
| Page title | Webページ | ページの題名 |
| Content width | フレーム | コンテンツの幅。空なら全幅 |
| Rules for every page | ファイル | すべてのWebページに効くこと（文章） |

## 6. noteを書く

Figmaのプロパティでは伝わらないことをレイヤーのnoteに自由な文章で書いてSaveする。Framesタブでフレームの行を開くとレイヤーが並び、レイヤーの行を押すと詳細にnoteの欄が出る。Figmaのキャンバスでレイヤーを選んだときのプロパティパネルにも、noteを開く入口が出る。noteのあるレイヤーの行には ✎ が付く。

書くことの例は次のとおり。

- 動き: スクロールしても画面の上に固定する
- ホバー・操作: ホバーで背景を濃くする。押すと詳細ページへ
- リンク先: `/signup?plan=pro`
- 意図: このプランをいちばん目立たせたい
- アクセシビリティ: 読み上げ用のラベルは「会社ロゴ」

渡らないレイヤーに書いたnoteはzipの `README.md` に「含まれなかったもの」として書かれる。

## 7. テーマを切り替えて確かめる

Themesを決めたら、上部のテーマの切り替え（`Light | Dark` のように、決めたテーマが並ぶ）を押す。選んだFigmaのページ全体で、変数のつながりが、そのテーマのサフィックスの変数に付け替わり、キャンバスでダークを確かめられる。最初のテーマを押すと戻る。最初のテーマ以外のまま閉じたファイルを開くと戻すよう促される。

## 8. 作りながらReviewする

Reviewは、キャンバスで選んでいるレイヤーのあるWebページを確かめ、上部にerrorとnoticeの件数を出す。Framesタブで別のWebページを選んで確かめてもよい。errorは直さないとExportできないもの、noticeは知らせるだけのもの。Figmaで直したあとは上部のReviewボタンで走らせ直す。

errorとnoticeはそれを直す判断の対象の行に付く。ファイル全体のことはファイル、色や数値のことはTokensタブのトークンの行（どのトークンとも違う値は、Tokensタブに値の行として並ぶ）、それ以外はフレームやレイヤーの行。行を押すと、詳細に内容と使っている箇所が並び、使っている箇所を押すとFigmaでそのレイヤーが選ばれる。同じ原因（同じ色の30か所など）は1行にまとまる。

| 種類 | 出るとき | 直し方 |
|---|---|---|
| error | Themesがあるのに、変数につないでいない色がある | 最初のテーマの変数か、サフィックスの無い変数につなぐ |
| error | あるテーマ・幅のサフィックスの変数に、ほかのサフィックスの相手が無い（`Color-light` のbgに対し、`Color-dark` にbgが無い） | 相手の変数を作る |
| error | フレームの幅と違う幅の変数を使っている（`top-mobile` で `Spacing-pc` の変数） | そのフレームの幅の変数につなぎ直す |
| error | 1つのWebページに、同じ幅のサフィックスのフレームが2つ以上ある | どちらかの名前を直す |
| notice | トークンと同じ値なのに、つないでいない | そのトークンにつなぐ |
| notice | Webページに、Breakpointsのうち描いていない幅がある | 描くか、そのままにする（描いた幅からCCが作る） |

## 9. まとめてExportする

作り終えたら、上部のExportを押す。FramesタブでExportにチェックが入ったWebページ（はじめは全部）を、まとめてReviewしてから書き出す。errorが残っていると止まり、一覧がerrorの行だけに絞られる。errorが0ならzipをダウンロードする。Themesがあれば、テーマごとの画像も入り、終わると（失敗しても）最初のテーマに戻る。

zipには、CCへの指示の `prompt.md` と、入っているものと含まれなかったものを書いた `README.md` が入る。zipをコードを作るフォルダに置き、CCに「このzipの `prompt.md` のとおりにページを作って」と伝える。

## できたかを確かめる

zipの `README.md` の「含まれなかったもの」が思ったとおりかを見る。CCがページを作ったら、幅とテーマを切り替えたスクリーンショットを、zipの中の画像と比べる。
