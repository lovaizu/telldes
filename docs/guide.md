# Figma のデザインを、CC に渡す zip にする

Figma のファイルを用意してから、Claude Code（以下 CC）に渡す zip ができるまでの手順。用意するものは、Figma（無償版でよい）と、Telldes を開ける状態（[README](../README.md) の「はじめる」）。

プラグインの画面には、Frames と Tokens の2つのタブがある。Frames には Web ページとそのフレーム・レイヤー、Tokens にはトークン（CC が CSS の変数にする色・数値・書体・文字・影）が並ぶ。一覧の行を押すと、その行の詳細が開く。ファイル全体の設定は、上部のファイル名を押すと開く。

## 1. Web ページを置いた Figma のページを選ぶ

ファイル全体の設定の Pages で、Web ページのフレームを置いた Figma のページを選ぶ。部品置き場や下書きのページは選ばない。

```
sample-site
├─ Visual Direction   ← 選ばない（下書き）
├─ Layout             ← 選ばない（下書き）
├─ Components         ← 選ばない（部品置き場。使った部品は、使った Web ページと一緒に渡る）
└─ Production         ← 選ぶ
```

選んだページの直下にある表示中のフレームが、Frames タブに並ぶ。フレームでないもの（直下に置いた Component・Rectangle など）と非表示のレイヤーは渡らず、Frames タブに Not exported として並び、zip の `README.md` にも書かれる。

## 2. 幅とテーマのサフィックスを決める

Telldes では、PC とスマホのような幅の違いと、ライトとダークのようなテーマの違いを、名前の末尾（サフィックス）で表す。Figma の無償版では、1つの変数に幅やテーマごとの値を持たせる機能（モード）が使えない。その代わりに、フレームにも変数にも同じサフィックスを付けると、Telldes が「同じものの幅違い・テーマ違い」としてまとめ、CC は幅とテーマで切り替わるページを作る。

ファイル全体の設定で、使うサフィックスを決める。

| 設定 | 例 | 決めること |
|---|---|---|
| Breakpoints | `-pc`（From width 1024）、`-mobile` | 幅ごとのサフィックスと、その幅を使い始める幅（From width）。一番狭いものは From width を空にする |
| Themes | `-light`、`-dark` | テーマごとのサフィックス。最初のものが、はじめに表示するテーマになる |

幅を1つしか描かないなら Breakpoints は空、ダーク対応しないなら Themes は空でよい。

### フレームに付ける

幅ごとに別のフレームで描き、フレーム名の末尾に幅のサフィックスを付ける。サフィックスを除いた名前が同じフレームが、1つの Web ページになる。

```
Production
├─ top-pc           ┐
├─ top-mobile       ┘ Web ページ「top」（PC とスマホ）
├─ article-pc       ┐
├─ article-mobile   ┘ Web ページ「article」
└─ campaign         ← サフィックスが無い。どの幅でもこの1枚を使う Web ページ「campaign」
```

テーマごとにフレームを描き分ける必要は無い。テーマは変数で切り替える（下）。

### 変数に付ける

幅やテーマで値を変えたい変数は、コレクション名か変数名の末尾にサフィックスを付けて、サフィックスごとに1つずつ作る。サフィックスを除いた名前が同じ変数が、1つのトークンになる。サフィックスの無い変数は、どの幅・テーマでも同じ値のトークンになる。

```
コレクション「Color-light」   bg = #FFFFFF   fg = #1A1A1A   ┐ トークン bg・fg
コレクション「Color-dark」    bg = #121212   fg = #EDEDED   ┘ テーマで切り替わる

コレクション「Spacing-pc」    section = 96                    ┐ トークン section
コレクション「Spacing-mobile」section = 48                    ┘ 幅で切り替わる

コレクション「Base」          radius/md = 8                   ← どこでも同じ
```

コレクション名の代わりに、変数名に付けてもよい（`bg-light` と `bg-dark`）。有料プランでモードを使うなら、モード名をサフィックスと同じ名前（`light`・`dark`）にすれば、同じように読む。

デザインでは、幅の違うフレームには、その幅の変数をつなぐ。`top-mobile` のフレームには `Spacing-mobile` の変数、`top-pc` には `Spacing-pc` の変数を使う。色は、最初のテーマ（`-light`）の変数につなぐ。

こうして渡すと、CC は `section` を「1024 から 96、それより狭いと 48」の CSS の変数に、`bg` を「ライトでは白、ダークでは黒」の CSS の変数にする。

## 3. Setup でトークンをそろえる

Tokens タブの Setup を押すと、推奨の一式のうち、足りないものだけが作られて Tokens タブに並ぶ。テーマで変わる色は、決めたテーマのサフィックスごとのコレクションに作られる。2回押しても増えず、手で作った同じ名前のものは上書きされない。足りないものがあるあいだは、Tokens タブに印が出る。名前はそのまま使い、値はデザインに合わせて変えてよい。

作られるものは次のとおり。

- テーマごとのコレクション（`Color-light`・`Color-dark` など）に、それぞれ14色: bg、surface、border、fg/default、fg/muted、primary/default、primary/hover、primary/on、link、code/bg、code/fg、notice/bg、notice/fg、shadow
- Base コレクション（どこでも同じ値）に、余白・角丸・書体
  - spacing: xs=4、sm=8、md=16、lg=24、xl=32、2xl=48、3xl=64、4xl=96
  - radius: sm=4、md=8、lg=16、xl=24、full=9999
  - font: heading、body、mono
- Text Style: display、heading-lg、heading-md、heading-sm、lead、body、label、caption、code
- Effect Style: shadow-sm、shadow-md

幅で変えたい余白などは、手順2のとおり、幅のサフィックスを付けたコレクションに作る。

## 4. デザインする

Figma のいつものやり方でデザインする。したことは、次のように CC に渡る。

| Figma でしたこと | CC に渡るもの |
|---|---|
| Auto Layout で並べた | 並び・間隔・伸び縮み |
| Auto Layout を使わずに置いた | 座標のまま（伸び縮みは伝わらない） |
| 変数・Text Style・Effect Style につないだ | トークンの名前 |
| つながずに値を入れた | 値のまま |
| Components のページの部品を置いた | 部品の中身ごと |
| 写真・ラスター画像 | PNG の画像 |
| アイコン・ロゴ（ベクター） | SVG の画像 |
| CSS で同じに描けないもの（特殊なグラデーション、破線など） | Figma が描いた画像 |

トークンになるのは、次のもの。

- 変数の Color と Number
- 変数の String のうち、使える場所（Scope）に Font family か Font style を含むもの
- Text Style と Effect Style

次のものはトークンにならず、Tokens タブに Not exported として並ぶ。使った所には値がそのまま渡る。

- Color Style。色は変数にする
- 変数の String のうち、文字の中身に使うもの（Scope が Text content）と、変数の Boolean

## 5. 決めることを欄に入れる

Frames タブの行を押すと、詳細に Export settings の欄が出る。入れたものはファイルに保存される。

| 欄 | 開く行 | 入れるもの |
|---|---|---|
| Page title | Web ページ | ページの題名 |
| Content width | フレーム | コンテンツの幅。空なら全幅 |
| Rules for every page | ファイル | すべての Web ページに効くこと（文章） |

## 6. note を書く

Figma のプロパティでは伝わらないことを、レイヤーの note に自由な文章で書いて Save する。Frames タブでフレームの行を開くとレイヤーが並び、レイヤーの行を押すと詳細に note の欄が出る。Figma のキャンバスでレイヤーを選んだときのプロパティパネルにも、note を開く入口が出る。note のあるレイヤーの行には ✎ が付く。

書くことの例:

- 動き: スクロールしても画面の上に固定する
- ホバー・操作: ホバーで背景を濃くする。押すと詳細ページへ
- リンク先: /signup?plan=pro
- 意図: このプランを一番目立たせたい
- アクセシビリティ: 読み上げ用のラベルは「会社ロゴ」

渡らないレイヤーに書いた note は、zip の `README.md` に「含まれなかったもの」として書かれる。

## 7. テーマを切り替えて確かめる

Themes を決めたら、上部のテーマの切り替え（`Light | Dark` のように、決めたテーマが並ぶ）を押す。選んだ Figma のページ全体で、変数のつながりが、そのテーマのサフィックスの変数に付け替わり、キャンバスでダークを確かめられる。最初のテーマを押すと戻る。最初のテーマ以外のまま閉じたファイルを開くと、戻すよう促される。

## 8. 作りながら Review する

Review は、キャンバスで選んでいるレイヤーのある Web ページを確かめ、上部に error と notice の件数を出す。Frames タブで別の Web ページを選んで確かめてもよい。error は直さないと Export できないもの、notice は知らせるだけのもの。Figma で直したあとは、上部の Review ボタンで走らせ直す。

error と notice は、それを直す判断の対象の行に付く。ファイル全体のことはファイル、色や数値のことは Tokens タブのトークンの行（どのトークンとも違う値は、Tokens タブに値の行として並ぶ）、それ以外はフレームやレイヤーの行。行を押すと、詳細に内容と使っている所が並び、使っている所を押すと Figma でそのレイヤーが選ばれる。同じ原因（同じ色の30か所など）は1行にまとまる。

| 種類 | 出るとき | 直し方 |
|---|---|---|
| error | Themes があるのに、変数につないでいない色がある | 最初のテーマの変数か、サフィックスの無い変数につなぐ |
| error | あるテーマ・幅のサフィックスの変数に、ほかのサフィックスの相手が無い（`Color-light` の bg に対し、`Color-dark` に bg が無い） | 相手の変数を作る |
| error | フレームの幅と違う幅の変数を使っている（`top-mobile` で `Spacing-pc` の変数） | そのフレームの幅の変数につなぎ直す |
| error | 1つの Web ページに、同じ幅のサフィックスのフレームが2つ以上ある | どちらかの名前を直す |
| notice | トークンと同じ値なのに、つないでいない | そのトークンにつなぐ |
| notice | Web ページに、Breakpoints のうち描いていない幅がある | 描くか、そのままにする（描いた幅から CC が作る） |

## 9. まとめて Export する

作り終えたら、上部の Export を押す。Frames タブで Export にチェックが入った Web ページ（はじめは全部）を、まとめて Review してから書き出す。error が残っていると止まり、一覧が error の行だけに絞られる。error が 0 なら zip がダウンロードされる。Themes があれば、テーマごとの画像も入り、終わると（失敗しても）最初のテーマに戻る。

zip には、CC への指示の `prompt.md` と、入っているものと含まれなかったものを書いた `README.md` が入る。zip をコードを作るフォルダに置き、CC に「この zip の `prompt.md` のとおりにページを作って」と伝える。

## できたかを確かめる

zip の `README.md` の「含まれなかったもの」が、思ったとおりかを見る。CC がページを作ったら、幅とテーマを切り替えたスクリーンショットを、zip の中の画像と比べる。
