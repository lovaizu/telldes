# E-3 完了条件チェック

## 完了条件チェックリスト

| 完了条件 | 判定 | 根拠 |
|---|---|---|
| セクションのスクリーンショットが必ず書き出されること | OK | depth=1 のノードは必ず PNG 2x で書き出し。テストで検証 |
| 子を持つブロックのスクリーンショットが書き出されること | OK | children を持つ depth>1 ノードを書き出し。テストで検証 |
| 末端エレメントのスクリーンショットが書き出されないこと | OK | children を持たない leaf ノードはスキップ。テストで検証 |
| ファイル名がレイヤーパスの `--` 結合で正しく生成されること | OK | "pricing > plans > plan-pro" → "pricing--plans--plan-pro.png"。テストで検証 |
| ラスター画像は PNG 2x、ベクターは SVG で出力されること | OK | IMAGE fill → PNG scale:2、VECTOR/STAR/POLYGON/LINE/BOOLEAN_OPERATION → SVG。テストで検証 |

## 総合判定

- セルフチェック: OK
- ユーザーレビュー可否: 可
