# N-1 完了条件チェック

## 完了条件チェックリスト

| 完了条件 | 判定 | 根拠 |
|---|---|---|
| ノード選択時に既存 note が表示されること | OK | selectionchange イベントで getPluginData("note") を取得し UI に送信。テキストエリアに表示 |
| テキスト入力→保存で pluginData に保存されること | OK | save-note メッセージで setPluginData("note", value) を実行 |
| 保存後にノードのプロパティパネルに relaunch ボタンが表示されること | OK | note が空でない場合 setRelaunchData({ editNote: "" }) を設定。空の場合はクリア |
| 別ノード選択時に UI が切り替わること（前ノードの note が残らないこと） | OK | selectionchange で新しいノードの note を送信し、noteText を更新 |

## 総合判定

- セルフチェック: OK
- ユーザーレビュー可否: 可
