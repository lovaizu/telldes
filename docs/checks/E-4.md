# E-4 完了条件チェック

## 完了条件チェックリスト

| 完了条件 | 判定 | 根拠 |
|---|---|---|
| チェックエラーがある状態では書き出しボタンが無効化されること | OK | run-export 時にチェックを再実行し、エラーがあれば export-error メッセージを返す。UIにエラー表示 |
| エラーゼロ時に zip がダウンロードできること | OK | エラーゼロ時に spec/tokens/screenshots/assets を UI に送信し、JSZip で zip 生成→ダウンロード |
| zip 内のディレクトリ構造が設計書 4.5 節に準拠すること | OK | telldes-export/{prompt.md, steering.md, spec.json, tokens.json, screenshots/, assets/} 構造 |
| tokens.json が Variables 定義時のみ含まれること | OK | tokens が null の場合 zip に tokens.json を追加しない |

## 総合判定

- セルフチェック: OK
- ユーザーレビュー可否: 可
