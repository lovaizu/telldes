## Triage

1. **Variable/Text-Style token collision at identical terminal path (silent data loss)** — Valid, confirmed independently (traced `setNested`'s terminal branch: leaf-vs-leaf collision has no `$base` slot available, since `$base` can only hold one displaced value — a leaf-vs-group collision only). A clean fix requires a schema/policy decision (not purely mechanical), since `$base` can't hold two colliding leaves. Escalated to the user with 3 options (extend tokens.json schema / treat as designer-facing announcement check / document as known limitation). **User decision (2026-07-02): add as a new suggestion-level announcement check under G-3** (detect the collision, warn the designer pre-export via G-3's check mechanism; tokens.json itself keeps its current last-write-wins behavior, documented as such). Action: add this as a new G-3 sub-item (or a new task) before G-3 is dispatched; docs/telldes-design.md 4.7.2 needs a short addition describing this check. G-2's own code does not need to change for this — the collision-avoidance work moves to G-3.
2. **`"typography/"` prefix duplicated across `tokensBuilder.ts` and `specBuilder.ts`** — Valid, minor, in-scope (both files already import from `src/util/typography.ts`; a shared exported constant is a natural, low-risk fix). **Resolved**: fix-round commit `ae69e99` adds `TYPOGRAPHY_TOKEN_PREFIX` to `src/util/typography.ts` and switches both call sites to reference it. Re-reviewed by fresh Language and Software-engineering experts against `git show ae69e99` (QA not re-run — its finding was unrelated to this one): both PASS, no residual duplication (grep confirmed the only other `"typography"` literal is the unrelated `$type: "typography"` DTCG discriminator), 130/130 tests still green, behavior byte-identical.
3. **tokens.json output-condition doc not yet updated for text-styles-only case** — Invalid / out-of-scope. This is G-5's explicit purpose (steering.md G-5, prerequisite "G-2 完了"); G-2's minimal null-condition fix (`supported.length === 0 && textStyles.length === 0`) was deliberately scoped narrow specifically so G-5 could do the fuller audit+doc update next. Rejected, no action within G-2.
