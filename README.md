# Telldes

Figma でデザインした LP / HP を、Claude Code（以下 CC）がカンプと同じ見た目に組めるかたちで渡せる Figma プラグイン。

## 何が楽になるか

カンプの画像だけを CC に渡すと、CC は色・大きさ・間隔の値や、どこが伸びてどこが固定か、動きやリンク先を画像から推し量る。推し量りは外れ、外れはページができてから見つかり、デザイナーは言葉で説明し直すことになる。

Telldes を使うと、Figma のファイルにある値がそのまま CC に渡り、ファイルに無いこと（動き・リンク先・どの幅で切り替えるかなど）も、渡す前にデザイナーが書き添えられる。このままでは正しく伝わらないところは、渡す前に Figma の中で分かる。デザイナーは説明し直さずに済み、CC は推し量らずに組める。

PC とスマホの幅違い、ライトとダークのテーマ違いも、Figma の無償版のまま1つのデザインとして渡せる。フレームと変数の名前の末尾をそろえるだけで、CC は幅とテーマで切り替わるページを作る。

## どう使うか

どの操作も、Figma の中で開いた Telldes の画面で行う。

1. Setup でデザインシステムを入れる

   幅違い（`-pc`・`-mobile` など）とテーマ違い（`-light`・`-dark` など）を表す名前の末尾を決め、Setup ボタンを押す。CC が CSS の変数にする色・余白・文字など（トークン）の推奨の一式が、ファイルに作られる

2. いつもどおりデザインする

   Figma の Auto Layout・変数・スタイル・コンポーネントで、1つのファイルに複数の Web ページを作る。幅違いのフレームと、幅やテーマで値を変える変数には、決めた名前の末尾を付ける

3. 伝わらないことは note にメモする

   動き・ホバー・リンク先・意図は、レイヤーごとの note（自由に書ける補足の欄）に書く。ページの題名など、CC が値として使うことは、決まった入力欄に入れる

4. 作りながら Review で確かめる

   Telldes は、今作っている Web ページで、CC に渡すものを確かめる。CC がデザインどおりに作れなくなるもの（error）は、直すまで Export できない。変数と同じ値なのに変数につないでいない色のような見落としは、止めずに知らせる。どちらも、それが起きているトークン・フレーム・レイヤーの行に出る。渡らないものも、ここで分かる

5. 作り終えたら Export で zip にする

   Export ボタンを押すと、選んだ Web ページがまとめて、CC への指示、トークン、フレームごとの中身の記述と画像、渡せなかったものの一覧の入った1つの zip になる。幅とテーマごとの画像も入る

6. CC に zip で実装を頼む

   zip をコードを作るフォルダに置き、CC に頼む。CC は中の指示どおりにページを組み、実装の判断（フォントの読み込み方など）は、CC を使ってページを作る人に確かめる

Figma での作り方の手順は [ガイド](docs/guide.md) にある。なぜこの形なのかは [設計書](docs/design.md) にある。

## 対象と、使うのに要るもの

Telldes が対象にしているのは、1人のデザイナーが作る LP / HP。

- Figma。無償版で動き、有料の機能は要らない
- 渡した zip からページを作る CC

## はじめる

Telldes は Figma Community で配っている。入れる手間は無く、Figma のファイルからそのまま探して動かせる。

1. Figma でデザインのファイルを開く
2. 左のナビゲーションの Tools を開き、Plugin に絞って「Telldes」を探す
3. Telldes を押して Run を押す。Telldes の画面が開く。ここから先は [ガイド](docs/guide.md) へ
