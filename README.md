# Telldes

FigmaでデザインしたWebページを、Claude Code（以下CC）がカンプと同じ見た目に組めるかたちで渡せるFigmaプラグイン。

## 何が楽になるか

カンプの画像だけをCCに渡すと、CCは色・大きさ・間隔の値や、どこが伸びてどこが固定か、動きやリンク先を画像から推し量る。推し量りは外れ、外れはページができてから見つかり、デザイナーは言葉で説明し直すことになる。

Telldesを使うと、Figmaのファイルにある値がそのままCCに渡り、ファイルに無いこと（動き・リンク先・どの幅で切り替えるかなど）も、渡す前にデザイナーが書き添えられる。このままではCCに誤って伝わるところも渡す前にFigmaの中で分かる。デザイナーは説明し直さずに済み、CCは推し量らずに組める。

PCとスマホの幅違い、ライトとダークのテーマ違いも、Figmaの無償版のまま1つのデザインとして渡せる。フレームと変数の名前の末尾をそろえるだけで、CCは幅とテーマで切り替わるページを作る。

## どう使うか

操作はすべて、Figmaの中で開いたTelldesの画面で行う。

1. Setupでデザインシステムを入れる

   幅違い（`-pc`・`-mobile` など）とテーマ違い（`-light`・`-dark` など）を表す名前の末尾を決め、Setupボタンを押す。CCがCSSの変数にする色・余白・文字など（トークン）の推奨の一式が、ファイルに作られる

2. いつもどおりデザインする

   FigmaのAuto Layout・変数・スタイル・コンポーネントで、1つのファイルに複数のWebページを作る。幅違いのフレームと、幅やテーマで値を変える変数には、決めた名前の末尾を付ける。部品のホバーや無効などの状態（バリアント）も描いておけばCCに伝わる

3. 伝わらないことはnoteにメモする

   動き・ホバー・リンク先・意図はレイヤーごとのnote（自由に書ける補足の欄）に書く。ページの題名など、CCが値として使うことは、決まった入力欄に入れる

4. 作りながらReviewで確かめる

   Telldesは、今作っているWebページで、CCに渡すものを確かめる。CCがデザインどおりに作れなくなるもの（error）があるうちはExportできない。変数と同じ値なのに変数につないでいない色のような見落としはExportを止めずに知らせる。どちらもそれが起きているトークン・フレーム・レイヤーの行に出る。CCに渡らないものもここで分かる

5. 作り終えたらExportでzipにする

   Exportボタンを押すと、選んだWebページがまとめて、CCへの指示、トークン、部品とそのすべての状態、フレームごとの中身の記述と画像、渡せなかったものの一覧の入った1つのzipになる。幅とテーマごとの画像も入る

6. CCにzipで実装を頼む

   zipをコードを作るフォルダに置き、CCに頼む。CCは中の指示どおりにページを組み、実装の判断（フォントの読み込み方など）は、CCを使ってページを作る人に確かめる

Figmaでの作り方の手順は [ガイド](docs/guide.md) にある。なぜこの形なのかは [設計書](docs/design.md) にある。

## 対象と、使うのに要るもの

Telldesの対象はFigmaでWebページをデザインする人。

- Figma。無償版で動き、有料の機能は要らない
- 渡したzipからページを作るCC

## はじめる

TelldesはFigma Communityで配っている。入れる手間は無く、Figmaのファイルからそのまま探して動かせる。

1. Figmaでデザインのファイルを開く
2. 左のナビゲーションのToolsを開き、Pluginに絞って「Telldes」を探す
3. Telldesを押してRunを押す。Telldesの画面が開く。ここから先は [ガイド](docs/guide.md) へ
